# Hi, I'm Israel 👋

I'm a **Computer Engineering student** interested in the intersection of **Embedded Systems, IoT, Electronics, and Cybersecurity**.

I'm currently focused on learning by building — working with microcontrollers, sensors, communication protocols, connected devices, and the security challenges that come with them.

### 🔧 What I'm working on

* Embedded systems & microcontrollers
* IoT & connected devices
* Electronics & hardware interfacing
* MQTT & device communication
* Cybersecurity
* C/C++ and practical system development

### 🚀 Projects

**ESP32-S3 IoT RFID Door Lock**
An IoT-based access-control system built with an ESP32-S3, RFID, servo control, Blynk and MQTT, with authentication, TLS security and event logging.

**Custom Microcontroller-Controlled Relay Module**
A relay-control circuit using an optocoupler and transistor driver, exploring isolation, switching and practical electronics troubleshooting.

More projects coming as I continue building and learning.

### 🌱 A little about my journey

I started out building for the web, which gave me my first experience with programming and creating things from scratch.

As I progressed through Computer Engineering, I became more interested in what happens beyond the screen — microcontrollers, electronics, communication between devices, and eventually the security of those systems.

I'm now exploring that space through practical projects and continuous learning.
